# WeChatAgent 0.5.0-preview.3 语音更新包（仅升级）

本更新包用于从现有 WeChatAgent 0.4.0 升级语音功能，不是全新安装包。目标微信客户端版本固定为 \`4.1.10.27\`。更新包不包含微信程序本体；它会保留已有数据目录和已有的匹配微信客户端。

## 安装前检查

1. 确认现有 WeChatAgent 0.4.0 能正常启动，并确认其匹配微信客户端版本为 \`4.1.10.27\`。
2. 找到当前安装根目录。默认结构为 \`D:\\WeChatAgent\\app\` 与 \`D:\\WeChatAgent\\data\`；如果 \`app\\storage.ini\` 指向自定义数据目录，继续使用原来的路径，不要重新选择一个空目录。
3. 完整退出 WeChatAgent、DSH 和匹配微信，包括托盘中的进程。不要在微信仍运行时替换 \`version.dll\`。
4. 备份整个 \`data\` 目录或 \`storage.ini\` 指向的数据目录。至少保留 \`workspace\\config\`、\`workspace\\state\` 和现有微信客户端目录。
5. 如果现有匹配微信并不在数据工作区 \`workspace\\state\\hook\\wechat-4.1.10.27\`，先不要安装；更新包会保留这个路径中的客户端，而不会自动寻找任意微信安装。

## 更新步骤

1. 运行 \`WeChatAgent-Voice-Update-0.5.0-preview.3-x64.exe\`。
2. 选择与 0.4.0 相同的安装根目录。不要删除或手动合并旧数据目录。
3. 首次启动时，桌面程序会把新版源文件与运行时部署到原数据工作区，并自动登记随包提供的便携 Python 3.11 语音运行环境。无需在 Windows 安装 Python、Visual Studio 或 C++ 开发工具。
4. 完整退出并重开 DSH，使其重新加载新版本地语音插件。
5. 在 Windows 用户环境变量中设置 \`MIMO_API_KEY\`。例如 PowerShell：\`setx MIMO_API_KEY "YOUR_API_KEY"\`。不要把真实密钥写入源码、项目 JSON 或日志。\`setx\` 不会更新已运行进程的环境，因此需要从新进程启动 DSH 和 WeChatAgent。
6. 从 WeChatAgent 的“打开微信”入口启动匹配微信。启动器会核对微信版本、DLL 哈希和既有构建记录；如果微信仍在运行，先从托盘彻底退出后再试。不要手动强行覆盖 \`version.dll\`。
7. 先只对一个私聊启用语音。语音默认关闭；确认语音识别正常后，再测试 MiMo 语音合成和实际微信语音气泡。需要时再单独启用群聊。

## 回滚与限制

- 如果更新安装器提示版本、哈希或客户端路径不匹配，立即停止，不要绕过检查；保存错误日志并联系维护者。
- 若需回滚，先完整退出所有相关程序，再用原 0.4.0 安装器安装到同一程序目录。保留原数据目录备份，不能因为回滚而删除 \`data\` 或自定义数据目录。
- 云端构建成功只证明构建、清单和包完整性检查通过；它不等于已经在真实微信进程中完成语音发送验收。
- MiMo TTS 会把待朗读文本发送到小米 API。不要用云端合成处理不适合发送给第三方服务的内容。
