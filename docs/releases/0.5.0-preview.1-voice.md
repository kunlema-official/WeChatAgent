# WeChatAgent 0.5.0-preview.1 — voice integration preview

This is a source preview, not a signed or validated Windows installer.

## Included

- WeChat type-34 voice messages can be registered by the NT reader and fetched through an authenticated, whitelist-checked local endpoint.
- A standalone `dsh-voice-plugin` provides SILK-to-WAV decoding code, DSH `speechToText`/SenseVoice ASR integration, and MiMo v2.5 API / optional Edge TTS-to-SILK synthesis code. Real inference and network synthesis have not yet been run in this environment.
- Chat-level voice settings use WeChatAgent's existing account-default and per-chat override model.
- The model may request `RESPOND_VOICE` only when the trusted local chat setting allows it; otherwise the parser rejects that mode and asks for a format correction.
- TTS artifacts and native-send requests are validated, and pre-submission voice failures fall back to text.
- Installer staging now includes the plugin and the optional Windows voice dependency bootstrap.

## Known limitation

The adapter has a guarded `/SendVoiceMsg` path. `scripts/build-hook.ps1` fetches the voice-capable `mengyunqwq/wechat-hook` source if no local checkout exists, checks `Route_SendVoiceMsg`, and integrates it into the WeChatAgent Hook build. Real Windows/WeChat voice-bubble delivery remains unverified in this Mac-side source pass; if the native health check reports the sender unavailable, replies safely fall back to text. Do not copy the reference project's prebuilt `version.dll` into the WeChatAgent installation; build the integrated DLL from the checked source instead.

## Windows 11 validation required

- Build the native Hook and installer on Windows 11 x64 with the required Visual Studio C++ build tools and authorized WeChat 4.1.10.27 runtime.
- Install Python 3.11 x64 voice dependencies into `state/voice-runtime`.
- Enable DSH's `speechToText` service and `sensevoice-local` provider.
- Verify a single private chat first, then a group if required.
- Do not use this preview to overwrite a live 0.4.0 installation. Back up the existing workspace and data before testing a built installer.

Real SILK decoding, SenseVoice inference, MiMo API synthesis, native voice sending, and the Windows 11 installer have not been validated here. Full TTS voice replies must not be advertised as release-ready until a source-backed native Hook sender is implemented and validated against the supported WeChat build.
