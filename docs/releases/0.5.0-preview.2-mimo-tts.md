# WeChatAgent 0.5.0-preview.2 — MiMo TTS integration

This is a source preview, not a validated Windows installer.

## Included

- Xiaomi MiMo `mimo-v2.5-tts` is the default TTS backend, using the official OpenAI-compatible endpoint `https://api.xiaomimimo.com/v1/chat/completions`.
- The request places synthesis text in the `assistant` message and voice/style instructions in the optional `user` message, and requests WAV output as specified by Xiaomi's documentation.
- Added response Base64/RIFF validation and WAV-to-SILK conversion through ffmpeg + `pilk`, normalizing to 24 kHz mono PCM16 before encoding.
- Capped MiMo response-body size and added request/error-path tests using a mocked API response; API keys are not included in status or error text.
- Added `MIMO_API_KEY` environment-variable configuration; the key is never returned by status APIs or stored in `wechatagent.json`.
- Edge TTS remains available only when explicitly selected in `wechat.voice.ttsProvider`; MiMo failures do not automatically send the text to a second external provider.
- Updated chat bridge arguments, config validation, plugin status and unit tests.

## Validation

- `node --test scripts/test-voice-feature.mjs`: 14/14 passed.
- JavaScript syntax checks for the voice service, voice policy, DSH bridge, OneBot adapter and voice tests passed.
- Python compilation and `wav-to-silk.py --help` passed.
- Live MiMo API synthesis, real `pilk` encoding, Windows Hook build, WeChat voice-bubble sending and 0.4.0 in-place upgrade have not been run in this environment.

## Setup on Windows 11

1. Create an API key at the Xiaomi MiMo platform and set it as a user environment variable with `setx MIMO_API_KEY "YOUR_API_KEY"`.
2. Sign out and back into Windows, or launch both DSH and WeChatAgent from a fresh PowerShell process that inherits the variable.
3. Run `powershell -ExecutionPolicy Bypass -File .\scripts\setup-voice.ps1` to install the isolated Python 3.11 x64 audio dependencies.
4. Enable DSH `speechToText` / `sensevoice-local` for ASR. TTS uses MiMo's remote API and sends synthesis text to Xiaomi.
5. Build the native Hook with `npm run hook:build` on Windows 11 x64 with Visual Studio C++ Build Tools, then verify the exact WeChat 4.1.10.27 version and a real voice send/receipt before enabling voice replies for a chat.

Do not overwrite the installed 0.4.0 with this source preview. Back up the existing workspace and data before testing a Windows installer.

Official documentation: <https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis>.
