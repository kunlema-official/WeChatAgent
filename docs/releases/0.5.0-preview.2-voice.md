# WeChatAgent 0.5.0-preview.2 — voice integration source preview

This is a source preview, not a signed or validated Windows installer. It supersedes preview.1.

## Changes since preview.1

- The native Hook build script now clones the reference voice-enabled Hook source into local `state/`, detects `Route_SendVoiceMsg`, and includes it in the WeChatAgent Hook build.
- Native Hook health reports voice-send capability only when the build includes the route and the detected WeChat core is `4.1.10.27`.
- The voice route and `/Debug/VoiceSend` are guarded by the same loopback Bearer Token gate, plus an exact single-account/version check.
- The OneBot adapter enables the voice-send switch only on first use from a chat whose WeChatAgent voice setting is enabled; it creates the persistence marker in the matching client directory.
- If the voice-switch endpoint is absent or fails before audio submission, the adapter sends text instead and skips TTS.
- Setup attempts to install the isolated Python 3.11 voice environment when the Windows Python Launcher is available; setup continues if optional voice dependencies cannot be installed.
- Voice status now reports the adapter's actual native-send capability when its local status endpoint is reachable.

## Existing voice pipeline

- Type-34 voice messages are fetched from `VoiceInfo.voice_data` through an authenticated, per-chat-whitelist reader endpoint.
- `dsh-voice-plugin` decodes SILK, calls DSH `speechToText`/SenseVoice, and generates outgoing SILK through Edge TTS.
- The model may select `RESPOND_VOICE` only when the local chat setting enables voice. WeChatAgent remains responsible for executing the mode and falling back safely.

## Validation boundary

On this Mac-side environment, the focused voice suite passes 10 tests, and JavaScript/Python static checks are run before packaging. The C++ Hook has **not** been compiled here; the `mengyunqwq/wechat-hook` source clone, real SenseVoice inference, Edge TTS network synthesis, and real WeChat voice-bubble send/receipt must still be tested on Windows 11 x64 with WeChat `4.1.10.27`. Do not overwrite the live 0.4.0 installation with this source ZIP. Back up the active workspace before testing an installer.

The Hook fork and its binary are not bundled. The build script records the exact local Git commit and DLL SHA-256 in `state/hook/native/build.json`. Verify licensing before public redistribution.
