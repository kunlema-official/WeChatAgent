# 记忆可视化

左侧 **记忆** 页面集中展示当前微信账号的数据，聊天详情中也有快捷入口。只读查看不会调用模型、创建会话、压缩上下文或改写记忆。

## 群友记忆

选择已保存允许范围中的群聊，可按昵称、成员 ID、标签查找，也可筛选“多次观察”“待观察”“尚无标签”。每位群友展示互动标签、有效证据数量、最近互动时间；展开“成员身份与记录”可查看稳定标识、历史昵称和首次记录时间。同名或改名的群友不会合并，其他群的标签也不会混入。

标签仅是有限互动观察。少于 3 条独立证据为待观察，90 天前的证据不再计入。关闭此群的记忆记录后，页面仍可查看已保存数据。这里不保存或展示证据发言原文。

数据来自工作空间下 `state/member-memory/<当前账号标识>/<群聊ID>.json`。

## 压缩记忆

按聊天选择会话，以时间排列摘要，可筛选来源、展开或收起正文、复制摘要。不同模式会标明“聊天模式”“助手任务”或“助手群聊”。

- **本地历史摘要**：从当前账号 `state/chat-history/<账号标识>/history.sqlite` 中只读查询 checkpoints，供历史检索使用。无需 DSH 在线也可查看。
- **DSH 原生压缩**：读取本地档案已保存的原生压缩摘要，并合并 DSH 已加载会话中的最新摘要。不会为了查看而创建或恢复 agent；DSH 未连接时仍可查看已保存的摘要。

页面展示最近 200 份本地历史摘要、最近 50 份已保存或已加载会话的原生摘要并分页。更早的数据保留在原位置；单份长摘要最多预览 60,000 字符。没有摘要时明确显示空状态，不会自动生成。摘要可能遗漏细节，不能当作完整聊天原文。数据库读取在独立工作线程进行，超时会停止本次读取，不阻塞控制台。

记忆按当前账号隔离。账号切换后刷新页面，旧账号标识的详情请求会被拒绝。损坏的 JSON、数据库暂不可读或不安全的目录链接会显示错误，原始文件保留。此页面不提供编辑、清空或删除操作。
