# 鱼的记事本（可选插件）

鱼的记事本已从常驻内置实现拆为 **WeChatAgent API v2 ZIP 插件**。实际写日记、人设回应、询问次数和每日去重逻辑在插件包内；宿主保留原来的微信触发、可靠发送、旧文件读取和前端展示入口。

## 文件位置与安装

- 插件源码：`optional-extensions/fish-notebook/`。
- 可安装文件：`release/plugins/fish-notebook-1.0.0.zip`。
- 前端入口：**记忆 → 鱼的记事本**，也可在此下载 ZIP；安装管理在 **能力 → 能力目录**。

先使用包含本次宿主扩展的新版源码：执行“准备项目配置”，完整退出并重开 DSH，再重开 WeChatAgent 窗口与后台。旧安装器不会因源码改变而自动升级；只有基础 API v2、缺少 actions / documents / 模型工具 / 每日计划能力的宿主，不能完整运行本包。

将 ZIP 拖入能力目录，确认安装；再在插件卡片点击“配置”，授予所需权限、选择聊天并启用。默认关闭，不自动替用户授予权限或安装。总开关、晚间时间和聊天范围改由插件配置统一管理，旧 `wechat.fishNotebook` 字段保留兼容，但不再启动内置记事本任务。

## 保留的行为

开启后，模型按本聊天当前人设，以第一人称记录当天事情、心情与联想。实际事件只依据当天有限聊天文字；不读取内部推理、工具日志或其他聊天。每个账号、聊天、人设、日期保存一篇，正文最多 1000 字符。

- **晚间自动写**：默认北京时间 21:30。后台服务与 DSH 正常运行、聊天空闲且有当天记录时写入；失败稍后再试。没有当天聊天时等待后续检查。
- **提前写**：第一次被问起或前端点击“写下今天”可提前生成。写成后，当晚不会再调用模型重写。
- **微信查看**：例如“看看你的日记”“鱼的记事本给我看看”，短时间内可接着说“再给我看看嘛”。同一人当天前两次由模型按人设害羞回应，第三次分享已保存日记，之后可直接看。按稳定成员标识区分，同名群友不混计；同一条消息重试不增加次数，重启后继续。
- **前端查看**：沿用“记忆 → 鱼的记事本”，保留历史、日期、人设与段落；直接查看不增加微信询问次数。
- **发送**：通过现有 Bridge 去重、限流和回执链路。分享日记时作为完整一页发送，不先拆出标题。日记不会在晚间写好后主动发到微信。

## 旧数据与开关

插件兼容原位置：

```text
state/fish-notebook/<账号作用域>/<会话哈希>/<日期-人设标识>.json
```

旧日记和询问回执直接继续使用，不移动、不复制或覆盖旧内容。长人设沿用完整签名计算日记标识，模型仍只接收受限的人设片段。损坏 JSON 保留并报告错误，不当作空白日记替换。关闭、更新、卸载仍保留已写日记，前端可继续阅读；重新安装相同 id 可继续使用。

本机授权与时间保存到 `config/plugins.json`。首次安装不自动继承旧全局开关为插件权限；请明确选择权限和聊天。原来的记事本设置接口只提供迁移提示，避免两套开关互相覆盖。

## 消耗与权限

插件需要 documents、history_read、persona_read、model_generate、schedule、reply。生成日记与前两次人设回应使用现有 DSH 模型并计入当前聊天用量；第三次分享直接返回已保存正文，不再生成。独立模型请求不挂载任何工具，不创建普通 DSH 任务或改写主会话人格。

群聊继续遵守既有允许范围与唤醒规则，不赋予普通群友执行 DSH 任务、读取其他聊天或访问任意文件的权限。

插件包自己的 [README](../optional-extensions/fish-notebook/README.md) 提供安装说明，通用宿主契约见 [插件开发规范](PLUGIN_DEVELOPMENT.md)。本次源码修改不会自动安装插件、修改用户开关或重启程序。
