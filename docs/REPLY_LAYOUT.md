# 分条发送设置

入口：**设置 → 聊天默认值 → 分条发送 → 单次回复最多分条数**。

设置范围为 0–20，默认保持 2：

- **0**：不设单次回复的条数上限，由模型根据内容决定分段数量，可以超过 20 条。
- **1**：整条发送，保留正文换行。
- **2–20**：单次最多发送相应条数。多余段落合并进最后一条，不丢弃正文。

模型以一个空行划分独立消息，单个换行用于消息内部排版。简短回复不为凑条数拆句；代码、完整列表、引用及连续说明保持完整。0 仅取消条数上限，文字长度、模型输出限制和原有发送频率仍然生效，不会增加模型请求次数。

此设置用于普通聊天回复和助手任务的最终对话回复。到期提醒、主动消息、进度、审批和状态提示保留现有发送包装。保存设置后用于新轮次，无需再次重启；正在处理或等待发送的回复保留原分段与投递编号，调整设置不会导致重发。

如果需要停止尚未发送的长回复，私聊发送 **停止分段**，群聊请 @ 助手后发送。已经确认送达的内容保留；正在提交的一条仍以微信回执为准。此指令不取消 DSH 正在执行的任务；取消助手工作任务仍使用“取消任务”。

分段逐条确认回执。某条送达未知时停止后续部分，避免重复；明确未提交的暂时失败可以按原编号恢复。旧版本前两条和表情的投递编号保持兼容，第三条起使用各自独立编号，重启后只续发未完成部分，不需要归档重开会话。

手工配置位置：`wechat.replyLayout.maxMessages`。首次安装包含此功能的修正版需完整重开 DSH、WeChatAgent 窗口和后台，此后数值调整可直接保存。
